# Подключение и диагностика доступа

Coagram — MCP-сервер `https://coagram.alven.studio/mcp` (Streamable HTTP, вход по OAuth). Токена в плагине нет:
клиент открывает страницу входа Coagram, человек входит сам и выбирает аккаунты и права. Пароли, коды Telegram,
токены у человека не спрашивай и никуда не вводи: вход и выбор прав — только его действия в браузере.

## Подключить

| Клиент | Вход |
|---|---|
| Codex, ChatGPT | `codex mcp login coagram`; в приложении — плагин Coagram → «Подключить» |
| Claude Code | `/mcp` → `coagram` → Authenticate |
| claude.ai, Claude Desktop | Настройки → Коннекторы → Coagram → Подключить |
| Другие | MCP-сервер `https://coagram.alven.studio/mcp`, OAuth с динамической регистрацией клиента |

На странице согласия человек выбирает:
- аккаунты Telegram, к которым агенту можно обращаться;
- права: `telegram:read` — чтение (отмечено по умолчанию); `telegram:write` — отправка, ответ, пересылка, правка и
  удаление своих сообщений, реакции, прочтение, черновики, закреп, файлы; `telegram:export` — экспорт истории;
  `telegram:manage` — служебные функции TDLib (`tdlib_*`), только при доступе ко всем чатам;
- для каждого аккаунта — все чаты или выбранные, с чтением, отправкой и экспортом по каждому чату.

Доступ живёт час и обновляется сам до 30 дней. Смена пароля Coagram, удаление аккаунта и отзыв подключения в
кабинете прекращают его сразу.

## Проверить, что есть

1. `telegram_accounts`: аккаунты подключения, `status` (`ready` — вошёл в Telegram), `chat_access` (`all` или
   `selected`) и `limitations` (`restricted_accounts` — аккаунты с выбором чатов).
2. Список инструментов: нет `telegram_send_message` — нет права `telegram:write`; нет `telegram_export_history` —
   нет `telegram:export`; нет `tdlib_*` — нет доступа ко всем чатам хотя бы одного аккаунта.

## Ошибки

| Ответ | Что значит | Что делать |
|---|---|---|
| HTTP 401, «Invalid, expired or revoked access token» | Доступ истёк или отозван | Войти снова (таблица выше) |
| HTTP 403 «Access denied», `insufficient_scope` | У подключения нет нужного права | Войти снова и отметить право; старое подключение сохраняет прежние права |
| `chat_access_denied` (-32000) | Чат или действие не выбраны для этого подключения | Кабинет Coagram → Подключения → Настроить чаты; действует со следующего запроса |
| `restricted_capability` | Подключение с выбором чатов: нет `tdlib_*`, `file_id` без чата, общего счётчика непрочитанного | Инструменты `telegram_*` с `chat_id`; или доступ ко всем чатам |
| `account_not_ready` | Аккаунт не вошёл в Telegram | Человек входит в кабинете Coagram: телефон, код, пароль 2FA |
| `telegram_unavailable` (503) | На сервере нет TDLib или ключей Telegram | Баг-репорт по навыку `feedback`, `area: access` |
| `storage_low` (503) | На сервере мало места | Повторить позже; повторяется — баг-репорт |
| `rate_limited` | Слишком часто | Подождать `retry_after` |

Клиент упорно просит только чтение — в настройках подключения клиента выбери нужные права (scopes) и войди снова.
Сервер обновился, а инструменты старые — переподключи коннектор (Claude Code: `/mcp` → Reconnect; Codex — новая
сессия); повторный вход не нужен.

Отказ, который этот навык не объясняет, или доступ ведёт себя вопреки описанному — баг-репорт по навыку `feedback`
с `area: access`.
